CLASSIFICATION MODEL EVALUATION RESULTS
========================================

Dataset: FARS (Fatality Analysis Reporting System)
Number of observations: 100,968
Number of features: 29
Target variable: INJURY_SEVERITY

Train-test split: 80% training, 20% testing
Cross-validation: 3-fold StratifiedKFold
Hyperparameter tuning: RandomizedSearchCV
Scoring metric: Macro F1-score

OBSERVATIONS
------------

- Random Forest achieved the highest test Macro F1-score.
- Logistic Regression achieved the highest test Accuracy and Balanced Accuracy.
- Performance varies considerably across injury severity classes.
- Rare classes remain challenging due to class imbalance.

Note: These metrics represent the reported test-set results.
